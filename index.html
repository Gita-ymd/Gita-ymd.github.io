Projeto 01 · LiderançaEm produção

Vision

Plataforma de inteligência de preços para o Ceya Supermercados (Duartina, SP), em produção no Azure. Scrapers para Magento GraphQL, Oracle Commerce e VTEX coletam mais de 38 mil produtos às 4h e às 12h, um matcher com filtros de tokens, marcadores, quantidade e preço pareia o mesmo item entre lojas, e alertas direcionais avisam a cada alta ou queda.

Inclui login com JWT e Google, papéis de acesso, painel administrativo, cache e 76 testes automatizados. Na disciplina de PLN, estamos levando o matching para uma abordagem com NER, que reconhece marca, volume e variante.

  • Python
  • FastAPI
  • SQLAlchemy
  • Azure SQL
  • React 19
  • APScheduler
  • GitHub Actions
  • NER
Projeto 02POC · Mercado imobiliário

ScoreLoft

Prova de conceito para a Loft que ordena imobiliárias por estrutura cadastral. Cruzamos 153 perfis com dados abertos da Receita Federal, consolidamos 83 CNPJs e montamos um score por percentis de idade, estabelecimentos e municípios, com auditoria de cada vínculo e análise de sensibilidade.

O projeto deixa explícito o que o score não mede: não é probabilidade de negócio e não há modelo supervisionado sem dados validados. A próxima etapa prevê regressão avaliada por MAE e Spearman.

  • Python
  • pandas
  • Dados abertos
  • Qualidade de dados
  • Docker
  • Testes

Projeto 05Protótipo · Ibmec

Agente de LinkedIn

Agente em LangGraph no padrão ReAct que consulta o perfil profissional por tool calling, pede esclarecimento quando falta informação, gera o rascunho no estilo do usuário e reprova qualquer fato não autorizado antes de pedir aprovação. Estado persistido em SQLite para retomar a conversa em outro processo, com testes que simulam o LLM.
